# trucks-go-home.github.io

The website of the Android game **Trucks Go Home**, served by GitHub Pages at
https://trucks-go-home.github.io

- `index.html`: the game's page
- `privacy.html`: the privacy policy linked from Google Play
- `app-ads.txt`: the ad sellers AdMob may use for the game; it must stay at the site's root

The font is Nunito, under the SIL Open Font License (`fonts/OFL.txt`).
